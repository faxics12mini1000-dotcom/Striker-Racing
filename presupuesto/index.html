Stack técnico

Lo que usamos para diseñar el auto

El software que necesitamos es gratuito para estudiantes; lo que financian los patrocinadores es el kit físico, el equipo y la logística, no las licencias.

Autodesk Fusion Gratis

Socio oficial de CAD/CAM/CAE de STEM Racing. Aquí modelamos el auto pieza por pieza y preparamos las trayectorias de maquinado.

Ansys Student Gratis

Incluye Ansys Discovery, socio oficial de CFD del torneo. Simulamos el flujo de aire sobre el auto antes de fabricar cada versión.

Equipo de cómputo

Las simulaciones de CFD exigen equipos con buena capacidad gráfica: es una de las áreas donde el apoyo de un patrocinador acelera directamente nuestro trabajo.

Kit de la categoría Desarrollo

Bloque de modelo oficial para el cuerpo, cartuchos de CO₂, ejes y armellas; el auto se maquina a partir de este kit.
